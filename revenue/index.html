如何启用这个页面

  1. 注册 爱发电 账号并完成实名，拿到形如 https://afdian.com/a/你的ID 的主页链接。
  2. 用文本编辑器打开本文件（revenue/index.html），把标注 TODO 的 href 换成你的真实链接。
  3. （可选）若有海外收款账户，同样填入 Ko-fi / Buy Me a Coffee 链接。
  4. （可选）接受 BTC 打赏：在文件底部脚本把 BTC_ADDRESS 换成你的 BTC 主网地址（以 bc1、1 或 3 开头）。填一处即可，复制按钮与 BIP21 钱包链接自动生效。BTC_AMOUNT 可设固定金额，留空由打赏者自填。注意：GitHub Sponsors 平台本身不处理加密货币，这是页面直挂的链上地址。
  5. 把本页部署到任意静态托管（GitHub Pages / Vercel / Netlify），或直接用 GitHub 仓库的 Pages 功能托管 revenue/ 目录。
  6. 在 README 与仓库首页挂上入口（本仓库已配好 .github/FUNDING.yml 与 README 链接）。
